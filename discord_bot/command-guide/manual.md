# 「守岸人」使用说明

本 bot 主要帮你看**角色培养进度**（面板、练度、声骸评分等）。

> 机器人自带的「帮助」图指令较多、且偏国服，**这里补一份面向国际服新手的简要说明**。
> 指令可用简体或繁体发送（收到后会先转成简体再匹配）；机器人文字回复一般为简体。
> **繁体出图：** 指令前加 `繁`（如 `繁莫宁面板`、`繁练度`），仅单角色面板与练度有效。
> **自选立绘：** 见下方「面板图集」。

如何获得机器人（加入支持服 / 邀请到你的服 / 自己部署）：见仓库 [README「怎么用」](https://github.com/jotenbai/WutheringWavesUID#怎么用三选一)。

**示例图片：** 与本文同目录下有若干 `.jpg` 示例，**文件名即对应指令名**（如 `体力.jpg` ↔ 指令 `体力`）。

## 1. 怎么跟机器人说话

| 场所               | 怎么发                                         | 谁看得见       | 适合                                |
| ------------------ | ---------------------------------------------- | -------------- | ----------------------------------- |
| **私聊**           | 直接发，无需 @；须先完成「服务器归属」（见下） | 只有你和机器人 | 不想让别人看到的内容（pcap 附件等） |
| **bot 专用频道**   | 直接发，无需 @（推荐在此完成首次归属）         | 同频道的人     | 日常查面板、练度、排行              |
| **服务器其它频道** | **必须 @ 机器人**，例如：`@守岸人 帮助`        | 同频道的人     | 偶尔查询                            |

**服务器归属：** 在任意服务器的频道里和机器人对话一次即可完成。完成前私聊只会收到去频道的提示。

**二次输入**（补图、回数字等）规则同上：专用频道 / 私聊直接回；其它频道每句仍须 @。也可把指令和内容写在同一条里（如 `分析` + 附图）。

**查看本 bot 其他用户的数据：** 在指令前 `@用户`，或在指令前加对方的游戏特征码，例如 `@某人 练度`、`701179473练度`、`701179473莫宁面板`。在非 bot 专用频道里，要**先 @守岸人 再 @对方**，例如 `@守岸人 @某人 练度`。只能查已在本 bot 留有数据的用户。

有时机器人会短暂无响应（定时重启、VPS 维护、更新代码后重启等）。可以先等一会儿再试；若仍不行，请在频道里反馈。

### 隐私与私聊

`.pcap` 可能含账号相关流量，更适合私聊附件或网页上传，别往公开频道丢。

**只能私聊的指令**（会暴露账号凭证或管理权限）：

| 指令                                | 在频道里发会怎样                                      |
| ----------------------------------- | ----------------------------------------------------- |
| `获取ck` / `获取token`              | 不执行（无提示）。登录凭证拿到就能冒用账号，切勿外传  |
| `修改抽卡记录`（仅主人 / 超级用户） | 提示改为私聊。管理员的编辑页可修改任意 UID 的抽卡记录 |

抽卡相关的其它操作（`导入抽卡链接`、普通用户的 `修改抽卡记录`）私聊和频道都能用。抽卡链接在有效期内谁打开都能看到你的抽卡历史，但不能登录账号或改动任何东西；介意的话改用私聊即可。发送 `.json` 文件导入抽卡记录需要主人开启「允许用户导入抽卡记录」，否则请把文件交给主人处理。

## 2. 怎么上手

### 三种录入方式怎么选

| 方式                         | 适合什么时候                                       | 改本地数据     | 上全服榜 |
| ---------------------------- | -------------------------------------------------- | -------------- | -------- |
| **pcap**（路径 A）           | 初次使用；声骸调整完毕后整体更新                   | 是（全部角色） | 是       |
| **分析官方 DC 卡**（路径 B） | 游戏内调整了某个角色后，想马上看它的面板           | 是（单个角色） | 否       |
| **单张声骸评分**（`尤诺1c`） | 尚未上线的角色；或在游戏中比较某角色两个声骸哪个好 | 否             | 否       |

**注意：** `刷新面板` 会用 pcap **整批覆盖**本地——`分析` 改过的角色会被盖回 pcap 版；本地排行（群 / bot）也会跟着变。

### 路径 A：练度 / 总排行（推荐完整）

1. `绑定<你的UID>` + `登录`（网页默认已选「国际服」，密码在库洛页输入，可能需 Geetest）
2. 抓包得到 `.pcap`：对本机器人发 `pcap帮助`，或看 [Wuthery Data Import Guide](https://wuthery.com/guides/1)
   - **PC：用 Method 2（Wireshark）**；**安卓：用 Method 3（PCAPdroid）**
   - **不要用 Method 1（Wuthery Sniffer）**：杀软常误报病毒
   - 加速器、VPN、代理、手机 USB/热点共享网络都可能导致解析失败，先关掉再抓；尽量 ≤4MB
3. `上传pcap`（网页，推荐）或 `解析pcap` + 附件
4. `刷新面板`（写入本地；已登录时同时上传全服排行）
5. 再查 `练度`、`莫宁面板`、`尤诺伤害总排行` 等

依赖 [Wuthery](https://wuthery.com) 解析；库洛侧抖动时上传可能失败，可稍后再刷。

> **版本更新后头几天：** 鸣潮一开新版本，Wuthery 的 pcap 解析常要跟几天协议，期间本 bot 的 `上传pcap` / `解析pcap` 也会失败（常见提示含 Incomplete data / 解析失败）。**这不是机器人故障。**  
> 可自行验证：看 [Wuthery Status](https://status.wuthery.com/) **第一行总状态**，或到 [Wuthery Import Data](https://wuthery.com/import) 用同一份 `.pcap` 试传。注意：**PCAP Server Health 绿灯只表示服务在线**，不等于已适配新版本；官网导入也失败时，请等 Wuthery 解析恢复后再传。这期间可用路径 B（`分析`）临时更新本地面板。

### 路径 B：只想先看一个角色（上手最快）

1. `绑定<你的UID>`
2. 用本群已邀请的官方 **wuwa bot** 出卡（无需进官方 Discord）。该 bot **不支持自然语言**，须依次用斜杠指令：
   1. `/bind` 绑定账号
   2. `/language` 改为**繁体中文**（英文/日文卡本机器人暂不支持）
   3. `/create` 创建角色卡片
   4. 右键卡片图 → **「复制链接地址」** 备用（须原图直链，勿用缩略图/预览链）  
      更细步骤见巴哈：[DC機器人製作個人角色卡](https://forum.gamer.com.tw/C.php?bsn=74934&snA=8077)
3. 对本机器人发送：`分析` + 粘贴直链（也可先发 `分析`，30 秒内补链接 / 图片）
4. `莫宁面板`（换成你分析的角色名）

官方卡一般读不到武器谐振，默认精 1。

## 3. 常用指令

角色名可换成你拥有的角色（支持常用别名）。

### 录入

| 指令                                 | 作用                                                                                  |
| ------------------------------------ | ------------------------------------------------------------------------------------- |
| `绑定701179473`                      | 绑定游戏 UID（特征码）                                                                |
| `查看` / `切换…` / `删除…`           | 查看、切换或删除绑定                                                                  |
| `登录`                               | 网页登录（体力等）                                                                    |
| `pcap帮助` / `上传pcap` / `解析pcap` | 抓包说明、网页上传、解析附件或查询是否已有数据                                        |
| `刷新面板`                           | 用 pcap 覆盖本地面板；已登录时可上传全服排行                                          |
| `分析` + 卡片直链                    | 识别官方 wuwa bot 繁体角色卡，只改本地面板                                            |
| `尤诺1c` + 图/链接                   | 单张声骸评分（不改面板）；`1`/`3`/`4` = C1/C3/C4，也可写 `尤诺c1`；无图则 30 秒内补发 |
| `上传矩阵` + 截图                    | 识别终焉矩阵战绩，之后发 `矩阵` 出图                                                  |

**`上传矩阵` 截图要求：**

- 矩阵战绩**不在 pcap 数据里**，需要单独 `上传矩阵`（藕粉椰果专用 ^\_^）
- 矩阵**每个游戏版本刷新一次**，新版本要重新上传；新版本第一次上传时会自动清空你的上期队伍，上期成绩仍可用 `上期矩阵群排行` / `上期矩阵bot排行` 查看
- 发游戏内「终焉矩阵」界面的**队伍列表截图**；**不支持分享图**
- 全屏截图即可，也可只截右侧队伍列表（需已 `绑定` UID）
- 队伍多时滑动列表多截几张，可一次发多张；按队伍编号合并，之后补传也会与已有记录合并
- 同一队在多张图里出现时，以最后上传的为准

## 4. 数据来源与排行规则

国际服**不能像国服那样从库街区一键拉全角色**，登录主要用于体力等；角色面板来自 **pcap 抓包快照**，旧 pcap 不会随游戏进度变，想更新就重新抓包上传再 `刷新面板`（已登录时同时更新全服榜）。三种录入方式的区别见第 2 节开头。

**排行有三种范围，不要混：**

|                  | **群排行**<br>（如 `尤诺伤害群排行`）                   | **bot 排行**<br>（如 `尤诺伤害bot排行`） | **全服总排行**<br>（如 `尤诺伤害总排行`） |
| ---------------- | ------------------------------------------------------- | ---------------------------------------- | ----------------------------------------- |
| 范围             | 本 Discord **服务器** / QQ **群**（须已完成服务器归属） | 本机器人上**所有已绑定**用户             | 接入的远端全服榜                          |
| 数据来自         | **本地面板库**（现场算）                                | 同左                                     | 远端排行库（由 `刷新面板` 上传）          |
| 怎么更新榜上成绩 | 本地有面板即可                                          | 同左                                     | 已登录 + pcap → `刷新面板`                |

群排行与 bot 排行合称**本地排行**。**群排行看的是哪个服务器：** 在频道里查 = 当前服务器；在私聊里查 = 你最近使用的服务器。bot 排行、总排行与在哪里查无关。

六类主要排行统一推荐使用“**种类 + 范围**”词序，例如 `维里奈伤害bot排行`、`维里奈评分bot排行`、`练度bot排行`、`持有率bot排行`、`共鸣链持有率bot排行`、`矩阵bot排行`；范围可换成 `群` / `bot` / `总`。兼容旧习惯的反向词序（如 `维里奈bot评分排行`、`bot持有率排行`、`bot练度排行`）。

- 省略**种类**时默认为伤害排行，例如 `维里奈bot排行` = `维里奈伤害bot排行`。
- 省略**范围**时默认为群排行，例如 `维里奈伤害排行` = `维里奈伤害群排行`，`持有率` = `持有率群排行`，`矩阵排行` = `矩阵群排行`。
- 要查远端全服榜必须显式写 `总`。
- **持有率：** 国际服本地持有率只统计有 pcap 的 UID。
- **矩阵排行：** 群 / bot 范围看本 bot 里 `上传矩阵` 的记录；`矩阵总排行` 只收国服账号经官方接口查询后自动上传的成绩，国际服截图识别的结果**不会**上传，所以国际服玩家不会出现在矩阵总榜。

**伤害 / 评分权重：** 伤害计算与声骸评分用的词条权重**始终与上游 MoonShadow1976 保持一致**，本 bot 不做改动；权重文件见上游 [utils/map/character](https://github.com/MoonShadow1976/WutheringWavesUID/tree/master/WutheringWavesUID/utils/map/character)（每个角色一个文件夹，`calc.json` 为权重）。部分角色（如心、菲比、锁暝）的权重会**随共鸣链不同而变化**（同目录 `condition.json`），按你本地面板里的共鸣链自动套用。如果与其它 bot 的结果不一致，通常是对方版本落后于上游。
