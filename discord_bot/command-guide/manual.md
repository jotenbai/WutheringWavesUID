# 守岸人 · 指令使用说明（国际服）

本 bot 主要帮你看**角色培养进度**（面板、练度、声骸评分等）。

> 机器人自带的「帮助」图指令较多、且偏国服，**这里补一份面向国际服新手的简要说明**。  
> 指令可用简体或繁体发送；机器人回复一般为简体。

**示例图片：** 与本文同目录下有若干 `.jpg` 示例，**文件名即对应指令名**（如 `体力.jpg` ↔ 指令 `体力`）。

---

## 1. 怎么跟机器人说话

| 场景       | 怎么发                                                                  |
| ---------- | ----------------------------------------------------------------------- |
| 私聊       | 直接发，例如：`帮助`、`守岸人面板`                                      |
| 服务器频道 | **必须 @ 机器人**（选自动补全里的账号），再写指令，例如：`@守岸人 帮助` |

未真正 @ 到账号时，频道里往往没有正文，机器人不会理你。频道里补发图片 / 链接时同样需要 @。

## 2. 数据来源

国际服**不能像国服那样从库街区一键拉全角色**，批量更新只能**手动上传 pcap**（也可用 `分析` 改单个角色的本地面板，详见下表）。

|              | **国服**                                              | **国际服**                                                              |
| ------------ | ----------------------------------------------------- | ----------------------------------------------------------------------- |
| 登录         | 手机号验证码登录库洛账号 / 库街区（与游戏同一套账号） | 邮箱密码登录库洛账号；主要用于**体力**等，**不能**一键拉全面板          |
| 角色面板     | 用登录凭证调库街区接口，`刷新面板` 时重新拉取         | **pcap 抓包快照**（一次导入几乎全部角色）                               |
| 更新面板     | 再发 `刷新面板`（或自动刷新）                         | **重新抓包上传新 pcap**，再 `刷新面板`；旧 pcap 不会随游戏进度变        |
| `分析` DC 卡 | 一般不需要                                            | 只改**本地面板**；**不更新 pcap**；**不影响全服榜**，但**会影响群排行** |
| 全服总排行   | 已登录 → 发 `刷新面板`（上传本次库街区数据）          | 已登录 + 已有 pcap → 发 `刷新面板`（上传的是 **pcap**，不是分析改动）   |
| 群排行       | 按本群成员的**本地面板**现场计算                      | 同样按本地面板；`分析` / `刷新面板` 改了本地后，查 `角色名排行` 就会变  |

**两种排行不要混：**

|                  | **群排行**（如 `尤诺排行`）            | **全服总排行**（如 `尤诺总排行`） |
| ---------------- | -------------------------------------- | --------------------------------- |
| 看谁             | 本群里绑过 UID、且本地有该角色面板的人 | 接入的全服榜                      |
| 数据来自         | **本地面板库**（不是 pcap 文件本身）   | 远端排行库（由 `刷新面板` 上传）  |
| `分析` 之后      | **会变**（分析写的就是本地库）         | **不变**                          |
| 怎么更新榜上成绩 | 本地有数据即可；查排行时现场算         | 已登录 + pcap → `刷新面板`        |

**国际服三条：**

1. `分析` 只改本地：**不更新 pcap**，**不上全服榜**，但**会进群排行**。
2. `刷新面板` 会用 pcap **整批覆盖**本地——分析改过的角色会被盖回；群排行也会跟着变回 pcap 版。
3. 想让**全服榜**反映新配装：重新抓包 → 上传 pcap → 已登录状态下 `刷新面板`。

## 3. 怎么上手

### 路径 A：练度 / 总排行（推荐完整）

1. `绑定<你的UID>` + `登录`（网页默认已选「国际服」，密码在库洛页输入，可能需 Geetest）
2. `pcap帮助`，或打开 [Wuthery Guides](https://wuthery.com/guides) → 抓包得到 `.pcap`（加速器可能导致失败；尽量 ≤4MB；勿含隐私）
3. `上传pcap`（网页）或 `解析pcap`（可带附件）
4. `刷新面板`（写入本地；已登录时同时上传全服排行）
5. 再查 `练度统计`、`守岸人面板`、`尤诺总排行` 等

依赖 [Wuthery](https://wuthery.com) 解析；库洛侧抖动时上传可能失败，可稍后再刷。

> **版本更新后头几天：** 鸣潮一开新版本，Wuthery 的 pcap 解析常要跟几天协议，期间本 bot 的 `上传pcap` / `解析pcap` 也会失败（常见提示含 Incomplete data / 解析失败）。**这不是机器人故障。**  
> 可自行验证：看 [Wuthery Status](https://status.wuthery.com/) **第一行总状态**，或到 [Wuthery Import Data](https://wuthery.com/import) 用同一份 `.pcap` 试传。注意：**PCAP Server Health 绿灯只表示服务在线**，不等于已适配新版本；官网导入也失败时，请等 Wuthery 解析恢复后再传。这期间可用路径 B（`分析`）临时更新本地面板。

### 路径 B：只想先看一个角色（上手最快）

1. `绑定<你的UID>`
2. 用本群已邀请的官方 **wuwa bot** 出卡（无需进官方 Discord）：`/language` 设为繁体中文 → 绑定账号 → 生成角色卡。详细教程：[DC機器人製作個人角色卡](https://forum.gamer.com.tw/C.php?bsn=74934&snA=8077)
3. 对本机器人发送：`分析 <卡片直链>`（也可先发 `分析`，30 秒内补链接 / 图片）
4. `守岸人面板`（换成你分析的角色名）

此路径**不上全服榜**，但本地有数据后查 `角色名排行` 会出现在**群排行**。有 pcap 后不要随便 `刷新面板`，否则会盖掉分析结果。官方卡一般读不到武器谐振，默认精 1。

### 其他

| 需求                | 做法                                                                                                |
| ------------------- | --------------------------------------------------------------------------------------------------- |
| 只查体力 / 先约电台 | `登录` 后发 `体力` / `mr`（不提供完整面板）                                                         |
| 只评一张声骸        | `尤诺1c` / `尤诺c1` + 附图或链接（`1`/`3`/`4` = C1/C3/C4；数字与 `c` 顺序可换）；无图则 30 秒内补发 |

## 4. 常用指令

角色名可换成你拥有的角色（支持常用别名）。同目录 `.jpg` 示例见文件名。

### 录入

| 指令                                 | 作用                                                      |
| ------------------------------------ | --------------------------------------------------------- |
| `绑定701179473`                      | 绑定游戏 UID（特征码）                                    |
| `查看` / `切换…` / `删除…`           | 查看、切换或删除绑定                                      |
| `登录`                               | 网页登录（体力等）                                        |
| `pcap帮助` / `上传pcap` / `解析pcap` | 抓包说明、网页上传、解析附件或查询是否已有数据            |
| `刷新面板`                           | 用 pcap 覆盖本地面板；已登录时可上传全服排行              |
| `分析 <图片链接>`                    | 识别官方 DC 角色卡（不更新 pcap、不上全服榜；会进群排行） |
| `尤诺1c` + 图/链接                   | OCR 声骸评分（不改面板）                                  |

### 查询自己的数据

| 指令             | 作用                                         | 示例图               |
| ---------------- | -------------------------------------------- | -------------------- |
| `守岸人面板`     | 单角色面板                                   | `守岸人面板.jpg`     |
| `练度统计`       | 多角色练度一览                               | `练度统计.jpg`       |
| `卡片` / `查询`  | 账号基本信息卡                               |                      |
| `声骸` / `声骸2` | 声骸相关一览                                 |                      |
| `尤诺排行`       | **群排行**：按本群成员本地面板现场计算       |                      |
| `尤诺总排行`     | **全服总排行**：远端榜（需 `刷新面板` 上传） | `尤诺伤害总排行.jpg` |
| `体力` / `mr`    | 体力等（需登录）                             | `体力.jpg`           |

### 资讯类（无需上传数据）

| 指令                                                           | 作用                     | 示例图       |
| -------------------------------------------------------------- | ------------------------ | ------------ |
| `尤诺天赋` / `尤诺技能` / `尤诺培养` / `尤诺攻略` / `尤诺图鉴` | 角色相关                 |              |
| `抗性` / `抗性表`                                              | 怪物抗性                 | `抗性表.jpg` |
| `武器列表`、`套装列表`、`声骸列表`                             | 列表类                   |              |
| `兑换码` / `code`、`公告`、`日历`                              | 兑换码 / 公告 / 活动日历 |              |
