# 「守岸人」· 指令使用说明（国际服）

本 bot 主要帮你看**角色培养进度**（面板、练度、声骸评分等）。

> 机器人自带的「帮助」图指令较多、且偏国服，**这里补一份面向国际服新手的简要说明**。  
> 指令可用简体或繁体发送（收到后会先转成简体再匹配）；机器人文字回复一般为简体。  
> **繁体出图：** 指令前加 `繁`（如 `繁莫宁面板`、`繁练度`），仅单角色面板与练度有效。  
> **自选立绘：** 可在 [图集站](https://core.jotenbai.moe/gallery/) 浏览 / 投稿；出图时用 `角色名面板` + 四位图号（如 `守岸人面板0001`）。

如何获得机器人（加入支持服 / 邀请到你的服 / 自己部署）：见仓库 [README「怎么用」](https://github.com/jotenbai/WutheringWavesUID#怎么用三选一)。

**示例图片：** 与本文同目录下有若干 `.jpg` 示例，**文件名即对应指令名**（如 `体力.jpg` ↔ 指令 `体力`；`守岸人面板0001.jpg` ↔ 指令 `守岸人面板0001`）。

## 1. 怎么跟机器人说话

三种地方都能用大部分指令，但 **Discord 私聊在完成「服务器归属」之前**，机器人会回复提示，请你先到服务器频道对话一次；之后私聊与频道功能一致。

| 场所               | 怎么发                                     | 谁看得见       |
| ------------------ | ------------------------------------------ | -------------- |
| **私聊**           | 完成归属后直接发；未归属会收到去频道的提示 | 只有你和机器人 |
| **bot 专用频道**   | 直接发（推荐在此完成首次归属）             | 同频道的人     |
| **服务器其它频道** | **必须 @ 机器人**，例如：`@守岸人 帮助`    | 同频道的人     |

二次输入（补图、回数字等）与上表相同：专用频道 / 私聊直接回；其它频道每句仍须 @。也可把指令和内容写在同一条里（如 `分析` + 附图）。

`.pcap` 可能含账号相关流量，更适合私聊附件或网页上传，别往公开频道丢。

有时机器人会短暂无响应（定时重启、VPS 维护、更新代码后重启等）。可以先等一会儿再试；若仍不行，请在频道里反馈。

## 2. 怎么上手

### 路径 A：练度 / 总排行（推荐完整）

1. `绑定<你的UID>` + `登录`（网页默认已选「国际服」，密码在库洛页输入，可能需 Geetest）
2. 抓包得到 `.pcap`：对本机器人发 `pcap帮助`，或看 [Wuthery Data Import Guide](https://wuthery.com/guides/1)
   - **PC：用 Method 2（Wireshark）**；**安卓：用 Method 3（PCAPdroid）**
   - **不要用 Method 1（Wuthery Sniffer）**：杀软常误报病毒
   - 加速器可能导致失败；尽量 ≤4MB；勿含隐私；公开频道慎发附件
3. `上传pcap`（网页，推荐）或 `解析pcap` + 附件
4. `刷新面板`（写入本地；已登录时同时上传全服排行）
5. 再查 `练度`、`莫宁面板`、`尤诺总排行` 等

依赖 [Wuthery](https://wuthery.com) 解析；库洛侧抖动时上传可能失败，可稍后再刷。

> **版本更新后头几天：** 鸣潮一开新版本，Wuthery 的 pcap 解析常要跟几天协议，期间本 bot 的 `上传pcap` / `解析pcap` 也会失败（常见提示含 Incomplete data / 解析失败）。**这不是机器人故障。**  
> 可自行验证：看 [Wuthery Status](https://status.wuthery.com/) **第一行总状态**，或到 [Wuthery Import Data](https://wuthery.com/import) 用同一份 `.pcap` 试传。注意：**PCAP Server Health 绿灯只表示服务在线**，不等于已适配新版本；官网导入也失败时，请等 Wuthery 解析恢复后再传。这期间可用路径 B（`分析`）临时更新本地面板。

### 路径 B：只想先看一个角色（上手最快）

1. `绑定<你的UID>`
2. 用本群已邀请的官方 **wuwa bot** 出卡（无需进官方 Discord）。该 bot **不支持自然语言**，须依次用斜杠指令：
   1. `/bind` 绑定账号  
   2. `/language` 改为**繁体中文**（英文/日文卡本机器人暂不支持）  
   3. `/create` 创建角色卡片  
   4. 右键卡片图 → **「复制链接地址」** 备用  
   更细步骤见巴哈：[DC機器人製作個人角色卡](https://forum.gamer.com.tw/C.php?bsn=74934&snA=8077)
3. 对本机器人发送：`分析` + 粘贴直链（也可先发 `分析`，30 秒内补链接 / 图片；**其它频道补发须 @**，专用频道 / 私聊直接发即可）
4. `莫宁面板`（换成你分析的角色名）

此路径**不上全服榜**，但本地有数据后会出现在**群排行 / bot 排行**（查 `角色名排行` 或 `角色名bot排行`）。有 pcap 后不要随便 `刷新面板`，否则会盖掉分析结果。官方卡一般读不到武器谐振，默认精 1。

### 其他

| 需求                | 做法                                                                                                |
| ------------------- | --------------------------------------------------------------------------------------------------- |
| 只查体力 / 先约电台 | `登录` 后发 `体力` / `mr`（不提供完整面板）                                                         |
| 只评一张声骸        | `尤诺1c` / `尤诺c1` + 附图或链接（`1`/`3`/`4` = C1/C3/C4；数字与 `c` 顺序可换）；无图则 30 秒内补发 |

## 3. 数据来源与排行规则

国际服**不能像国服那样从库街区一键拉全角色**，批量更新只能**手动上传 pcap**（也可用 `分析` 改单个角色的本地面板，详见下表）。

|              | **国服**                                              | **国际服**                                                                            |
| ------------ | ----------------------------------------------------- | ------------------------------------------------------------------------------------- |
| 登录         | 手机号验证码登录库洛账号 / 库街区（与游戏同一套账号） | 邮箱密码登录库洛账号；主要用于**体力**等，**不能**一键拉全面板                        |
| 角色面板     | 用登录凭证调库街区接口，`刷新面板` 时重新拉取         | **pcap 抓包快照**（一次导入几乎全部角色）                                             |
| 更新面板     | 再发 `刷新面板`（或自动刷新）                         | **重新抓包上传新 pcap**，再 `刷新面板`；旧 pcap 不会随游戏进度变                      |
| `分析` DC 卡 | 一般不需要                                            | 只改**本地面板**；**不更新 pcap**；**不影响全服榜**，但**会影响本地排行**（群 / bot） |
| 全服总排行   | 已登录 → 发 `刷新面板`（上传本次库街区数据）          | 已登录 + 已有 pcap → 发 `刷新面板`（上传的是 **pcap**，不是分析改动）                 |
| 本地排行     | 按本群 / 本 bot 绑定用户的**本地面板**现场计算        | 同样；`分析` / `刷新面板` 改了本地后，查 `角色名排行` / `bot排行` 就会变              |

**排行有三层，不要混：**

|                  | **群排行**<br>（如 `尤诺伤害群排行`）                   | **bot 排行**<br>（如 `尤诺伤害bot排行`） | **全服总排行**<br>（如 `尤诺伤害总排行`） |
| ---------------- | ------------------------------------------------------- | ---------------------------------------- | ----------------------------------------- |
| 范围             | 本 Discord **服务器** / QQ **群**（须已完成服务器归属） | 本机器人上**所有已绑定**用户             | 接入的远端全服榜                          |
| 数据来自         | **本地面板库**（现场算）                                | 同左                                     | 远端排行库（由 `刷新面板` 上传）          |
| `分析` 之后      | **会变**                                                | **会变**                                 | **不变**                                  |
| 怎么更新榜上成绩 | 本地有面板即可                                          | 同左                                     | 已登录 + pcap → `刷新面板`                |

群排行与 bot 排行合称**本地排行**（都看「守岸人」bot 库里的本地面板，不看远端总榜）。持有率同理：`持有率群排行` / `持有率bot排行`（国际服本地持有率只统计有 pcap 的 UID）。

五类主要排行统一推荐使用“**种类 + 范围**”词序，例如 `维里奈伤害bot排行`、`维里奈评分bot排行`、`练度bot排行`、`持有率bot排行`、`共鸣链持有率bot排行`；范围可换成 `群` / `bot` / `总`。兼容旧习惯的反向词序（如 `维里奈bot评分排行`、`bot持有率排行`、`bot练度排行`）。

- 省略**种类**时默认为伤害排行，例如 `维里奈bot排行` = `维里奈伤害bot排行`。
- 省略**范围**时默认为群排行，例如 `维里奈伤害排行` = `维里奈伤害群排行`，`持有率` = `持有率群排行`。
- 要查远端全服榜必须显式写 `总`。

**国际服三条：**

1. `分析` 只改本地：**不更新 pcap**，**不上全服榜**，但**会进群 / bot 排行**。
2. `刷新面板` 会用 pcap **整批覆盖**本地——分析改过的角色会被盖回；本地排行也会跟着变回 pcap 版。
3. 想让**全服榜**反映新配装：重新抓包 → 上传 pcap → 已登录状态下 `刷新面板`。

## 4. 常用指令

角色名可换成你拥有的角色（支持常用别名）。同目录 `.jpg` 示例见文件名。

### 录入

| 指令                                 | 作用                                                        |
| ------------------------------------ | ----------------------------------------------------------- |
| `绑定701179473`                      | 绑定游戏 UID（特征码）                                      |
| `查看` / `切换…` / `删除…`           | 查看、切换或删除绑定                                        |
| `登录`                               | 网页登录（体力等）                                          |
| `pcap帮助` / `上传pcap` / `解析pcap` | 抓包说明、网页上传、解析附件或查询是否已有数据              |
| `刷新面板`                           | 用 pcap 覆盖本地面板；已登录时可上传全服排行                |
| `分析` + 卡片直链                    | 识别官方 wuwa bot 繁体角色卡（不更新 pcap、不上全服榜；会进本地排行） |
| `尤诺1c` + 图/链接                   | OCR 声骸评分（不改面板）                                    |

### 查询自己的数据

| 指令                | 作用                                                                | 示例图               |
| ------------------- | ------------------------------------------------------------------- | -------------------- |
| `莫宁面板`          | 单角色面板（有自定义立绘时用图集图）                                | `莫宁面板.jpg`       |
| `守岸人面板0001`    | 同上，并**指定图号**（四位；图集站已通过的本图）                    | `守岸人面板0001.jpg` |
| `繁莫宁面板`        | 同上，**出图为繁体**（也可 `繁莫宁面板0001`）                       | `繁莫宁面板.jpg`     |
| `练度`              | 多角色练度一览                                                      | `练度.jpg`           |
| `繁练度`            | 同上，**出图为繁体**                                                | `繁练度.jpg`         |
| `卡片` / `查询`     | 账号基本信息卡（UID、等级、角色一览等）                             | `卡片.jpg`           |
| `声骸` / `声骸2`    | 声骸相关一览                                                        |                      |
| `维里奈伤害群排行`  | **群排行**：本服务器内已归属且有该角色面板的用户；兼容 `维里奈排行` | `维里奈排行.jpg`     |
| `维里奈伤害bot排行` | **bot 排行**：本机器人全部绑定用户                                  |                      |
| `尤诺伤害总排行`    | **全服总排行**：远端榜（需 `刷新面板` 上传）                        | `尤诺总排行.jpg`     |
| `体力` / `mr`       | 体力等（需登录）                                                    | `体力.jpg`           |

### 资讯类（无需上传数据）

| 指令                                                           | 作用                     | 示例图       |
| -------------------------------------------------------------- | ------------------------ | ------------ |
| `尤诺天赋` / `尤诺技能` / `尤诺培养` / `尤诺攻略` / `尤诺图鉴` | 角色相关                 |              |
| `抗性` / `抗性表`                                              | 怪物抗性                 | `抗性表.jpg` |
| `武器列表`、`套装列表`、`声骸列表`                             | 列表类                   |              |
| `兑换码` / `code`、`公告`、`日历`                              | 兑换码 / 公告 / 活动日历 |              |

### 面板图集

| 指令 / 入口                                  | 作用                                                               |
| -------------------------------------------- | ------------------------------------------------------------------ |
| [图集站](https://core.jotenbai.moe/gallery/) | 浏览已通过立绘、原图溯源；已绑定 UID 的用户可投稿；管理员审核      |
| `角色名面板1234`                             | 出图时使用指定图号（如 `守岸人面板0001`）；不存在则官方立绘 + 提示 |
| `更新图集` / `同步图集`                      | **主人 / 超级用户**：立刻把网页权威库同步到机器人本机              |

图号来自图集站每个角色目录下的 `0001.jpg`、`0002.jpg`…（与网页展示编号一致）。
