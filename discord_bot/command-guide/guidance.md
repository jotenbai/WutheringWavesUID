# 守岸人 · 指令使用说明（国际服）

> 机器人自带的「帮助」图指令较多、且偏国服，**这里补一份面向国际服新手的简要说明**。  
> 指令可用简体或繁体发送；机器人回复一般为简体。

**示例图片：** 与本文同目录下有若干 `.jpg` 示例，**文件名即对应指令名**（如 `体力.jpg` ↔ 指令 `体力`，`练度统计.jpg` ↔ `练度统计`）。

---

## 怎么跟机器人说话

| 场景       | 怎么发                                                                  |
| ---------- | ----------------------------------------------------------------------- |
| 私聊       | 直接发，例如：`帮助`、`守岸人面板`                                      |
| 服务器频道 | **必须 @ 机器人**（选自动补全里的账号），再写指令，例如：`@守岸人 帮助` |

未真正 @ 到账号时，频道里往往没有正文，机器人不会理你。

---

## 国际服：先弄清「数据从哪来」

本 bot 主要帮你看**角色培养进度**（面板、练度、声骸评分等）。国际服**不能像国服那样从库街区一键拉全角色**，需要你自己录入面板数据。常用四条路如下（② 最全，③ 上手最快）。

| 方式         | 指令 / 操作                                 | 适合             | 说明                                          |
| ------------ | ------------------------------------------- | ---------------- | --------------------------------------------- |
| ① 登录       | `登录`                                      | 体力、先约电台等 | **不提供**完整角色面板                        |
| ② pcap       | `pcap帮助` → 抓包 → `上传pcap` → `刷新面板` | **最全**         | 一次导入几乎全部角色；练度 / 总排行推荐       |
| ③ 分析 DC 卡 | `分析` + 官方角色卡图链接                   | 上手最快         | 单角色；无法获取武器谐振（精炼）数据，默认精1 |
| ④ 声骸 OCR   | `尤诺c1` 等 + 声骸图                        | 只评一张声骸     | 数字表示 C4/C3/C1；数字与 `c` 的顺序可换序    |

### ① 登录

发 `登录`，在打开的网页选 **OS 國際服**，用库洛账号完成登录（可能需 Geetest）。

**关于密码：** 账号密码是在**库洛 / 官方登录页**输入的，用于拉取体力等账号接口；本 bot 本身不另开一套「把密码发给维护者」的流程。若你暂时只想看面板、不需要 `体力`，可以先跳过登录，改用下面的 ③ 分析；要做练度统计 / 总排行上传，一般仍需要登录 + pcap。

### ② pcap

1. 发 `pcap帮助`，或打开 [Wuthery Guides](https://wuthery.com/guides)（含图文/视频）。
2. 按教程抓取登录进游戏时的网络包，得到 `.pcap`（注意：加速器等可能导致失败；文件尽量 ≤4MB；勿上传含隐私的包）。
3. 发 `上传pcap`，在网页上传；或用 `解析pcap`（可带附件；无附件时可查是否已有数据）。
4. 发 `刷新面板` 写入本地面板。国际服批量数据依赖 [Wuthery](https://wuthery.com) 解析服务。

**想刷全面板、上总排行、做练度统计：** 通常需要 **登录 + 至少成功导入过一次 pcap**，再 `刷新面板`。  
若之后又用「分析」改过单角色，再执行 `刷新面板` 时国际服会按 **pcap 数据**刷新，可能覆盖分析改过的内容。

### ③ 分析 DC 卡

1. **先在官方 Discord 用 WUWA BOT 生成角色卡**  
   步骤见：[DC機器人製作個人角色卡](https://forum.gamer.com.tw/C.php?bsn=74934&snA=8077)（进官方服 → 打开 BOT 频道 → `/language` → 绑定账号 → 用生成指令出卡）。

2. **再把卡片交给本机器人**  
   官方图一般是可直链的 URL（形如 `https://wutheringwaves-dc.kurogames-global.com/back/.../*.jpeg`）。对本机器人发送：

   ```text
   分析 https://wutheringwaves-dc.kurogames-global.com/back/51/51598b195960a7973f77e1fea5527879ae52f1f3.jpeg
   ```

   即：`分析` + 图片链接。也可以先只发 `分析`，再在提示后的 **30 秒内**补发链接或图片；**在频道里补发时同样需要 @ 机器人**。

3. 成功后用 `角色名面板`（如 `守岸人面板`）查看。分析**不会**自动进总排行。

### ④ 声骸 OCR

1. 发送形如 `尤诺1c` / `尤诺c1` 的指令（角色名可换；`1`/`3`/`4` 对应 C1/C3/C4 等）。
2. **同一条消息带上图片或图片链接**，例如：`尤诺1c` + 附图，或 `尤诺1c https://...`。
3. 若指令里没有图：机器人会提示你在 **30 秒内**补发声骸截图或链接；**频道里补发也必须 @ 机器人**，否则收不到正文。

请保证截图清晰，否则 OCR 容易失败。

## 一、上传 / 录入信息类

把数据「写进机器人」用的指令。

| 指令               | 作用                         | 备注                                            |
| ------------------ | ---------------------------- | ----------------------------------------------- |
| `绑定701179473`    | 绑定游戏 UID（特征码）       | 查询前先绑定                                    |
| `查看`             | 查看已绑定 UID               |                                                 |
| `切换…` / `删除…`  | 切换或删除绑定               |                                                 |
| `登录`             | 国际服网页登录               | 体力等；密码在库洛登录页输入，见上文①           |
| `分析 <图片链接>`  | 识别官方 DC 角色卡           | 见上文③；也可先发指令再补图（频道须 @）         |
| `尤诺1c` + 图/链接 | OCR 声骸评分                 | 见上文④；无图则 30 秒内补发（频道须 @）         |
| `pcap帮助`         | 抓包与导入说明               | 见上文②                                         |
| `上传pcap`         | 打开网页上传入口             | 上传 `.pcap`                                    |
| `解析pcap`         | 解析附件，或查询是否已有数据 | 无附件时可用于检查                              |
| `刷新面板`         | 用已有数据更新本地面板       | 国际服优先用 pcap；成功且已登录时可能上传总排行 |

**推荐完整路径（练度 / 总排行）**

1. `绑定` + `登录`
2. `pcap帮助` → 按教程抓包 → `上传pcap`
3. `刷新面板`
4. 再查 `练度统计`、`守岸人面板`、`尤诺总排行` 等

**推荐新手路径（只想先看一个角色）**

1. `绑定<你的UID>`
2. 按巴哈教程用官方 WUWA BOT 出卡 → `分析 <图片链接>`
3. `守岸人面板`（把角色名换成你分析的那只）

## 二、输出信息类（查自己的数据）

录入成功后再查。角色名可换成你拥有的角色（支持常用别名）。同目录示例图见文件名。

| 指令             | 作用              | 同目录示例           |
| ---------------- | ----------------- | -------------------- |
| `守岸人面板`     | 单角色面板        | `守岸人面板.jpg`     |
| `练度统计`       | 多角色练度一览    | `练度统计.jpg`       |
| `卡片` / `查询`  | 账号基本信息卡    |                      |
| `声骸` / `声骸2` | 声骸相关一览      |                      |
| `尤诺排行`       | 群内 / bot 内排行 |                      |
| `尤诺总排行`     | 接入的全服总排行  | `尤诺伤害总排行.jpg` |
| `体力` / `mr`    | 体力等（需登录）  | `体力.jpg`           |

**总排行说明**

- 发 `角色名总排行`（如 `尤诺总排行`）可查当前 bot 已接入的全服榜；示例见 `尤诺伤害总排行.jpg`。
- 你的成绩要出现在榜上：国际服一般需 **登录 + pcap**，再成功 `刷新面板`（库洛侧抖动时可能上传失败，可稍后再刷）。
