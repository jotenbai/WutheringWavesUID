================================================================================
一、项目目标
================================================================================

为鸣潮国际服搭建 Discord 机器人「守岸人」，核心能力是生成角色面板等。
用户是前端开发者（JS/HTML/CSS），Python 较弱；优先国际服，个性化以后再做。
小 VPS 自用，不打算大规模推广。

参考体验：与群里已有的纳西妲 bot 一致 ——
  - 私聊：无前缀，直接发「帮助」「练度统计」
  - 服务器频道：@机器人 后无前缀指令（如 @守岸人 帮助）
  参考：https://github.com/gamer-mitsuha/nahida-examples

| 本地仓库          | e:\编程\WutheringWavesUID_for_discord |

  ~/gsuid_core                          # core + 插件目录

  ~/discord_bot                         # nb 项目根目录（.env 在此）

四、Discord Bot 配置要点
================================================================================

开发者门户（Discord Developer Portal）— 守岸人：
  - Message Content Intent：**建议关闭**（仅需私聊 + 频道 @ 触发时不必开）
  - Bot 权限：View Channels, Send Messages, Read Message History,
              Attach Files, Embed Links

未开 message_content 时，adapter 仍能在以下场景收到完整消息（见 nonebot-adapter-discord README）：
  - 私信（DM）
  - 消息中 @ 了 Bot
  - 回复了 Bot 的消息

开启 message_content 会监听频道内所有消息，易误响应他人指令（如 @纳西妲 时守岸人也抢答），私域小群不建议。

~/discord_bot/.env 关键项（路径注意：不是 discord_bot/discord_bot/.env）：
  DRIVER=~httpx+~websockets
  DISCORD_BOTS=[{
    "token": "（勿写入本笔记，勿提交 git）",
    "intent": {
      "guild_messages": true,
      "direct_messages": true,
      "message_content": false
    },
    "application_commands": {"*": ["*"]}
  }]
  gsuid_core_host=127.0.0.1
  gsuid_core_port=8765
  gsuid_core_ws_token=

改 .env 后重启 discordbot；改门户 Intent 后也需重启 discordbot。

  - 踢出再邀请：仅在怀疑「邀请时权限给少了」时值得一试；对进程挂掉、配置错误帮助不大
  - DM 能回说明 Token/账号基本正常；频道问题优先查该 bot 的 guild 权限与后台进程

M. discordbot 日志 — Snowflake 编码错误（带图指令失败）
--------------------------------------------------------------------------------

现象（discordbot 日志）：
  TypeError: Encoding objects of type Snowflake is unsupported
  File .../GenshinUID/client.py ... msgjson.encode(msg)

原因：带图片消息里 attachment.id 是 Discord Snowflake 对象，转发给 core 时序列化失败。
纯文字「帮助」可以；「卡提4c」+ 附图会炸。

处理（在 VPS，先停 discordbot 再操作）：
  cd ~/discord_bot/discord_bot
  source .venv/bin/activate
  pip show nonebot-plugin-genshinuid nonebot-adapter-discord
  pip install -U nonebot-plugin-genshinuid nonebot-adapter-discord
  deactivate
  # screen -r discordbot → Ctrl+C → nb run → Ctrl+A D

若升级后仍报错（5.0.0 仍会炸）→ 手动补丁 __init__.py：

  # 停 discordbot：screen -r discordbot → Ctrl+C
  cd ~/discord_bot/discord_bot
  source .venv/bin/activate
  FILE=.venv/lib/python3.12/site-packages/GenshinUID/__init__.py
  nano $FILE
  # 搜索「处理 Discord 消息中的附件」或 model_dump(dc_attachment
  # 把 message.extend(Message(..., model_dump(...)), for ...) 整段
  # 换成下面 for 循环（核心是 att_data["id"] = int(att_data["id"])）：

  for dc_attachment in ev.attachments:
      att_data = model_dump(dc_attachment, exclude_unset=True)
      if "id" in att_data:
          att_data["id"] = int(att_data["id"])
      message.append(
          Message(
              (
                  "image"
                  if (content_type := dc_attachment.content_type) is not UNSET and "image" in content_type
                  else "attachment"
              ),
              att_data,
          )
      )

  deactivate
  nb run → Ctrl+A D → 再测「图 + 卡提4c」

判读：create_message = 纯文字成功；Snowflake = 带图失败（补丁前）。
